# Changelog

## 0.1.0 (2026-11-14)


### ⚠ BREAKING CHANGES

* Super+F no longer makes a window fullscreen and Super+N no longer makes a workspace: they are Super+Ctrl+F and Super+Ctrl+N, and Super+Tab is the switcher rather than the next tab, now Super+`. A chord with Super that nothing binds reaches programs as Ctrl; set
* omorfos needs PipeWire 1.4 or later, and its Debian package is built on Ubuntu 26.04, so it no longer installs on Ubuntu 24.04.
* **config:** a `keys.yaml` that left built-in bindings out on purpose gets them back. Add `defaults: false` to keep only your own, or list the ones to drop under `unbind`.
* **omorfos:** a panel, wallpaper setter, launcher or notification program that omorfos did not start with a role is refused. Write it in `autostart` as `{ run: [...], may: [panel] }`, or with `may: [overlay]` if it takes the keyboard. A screen locker is refused unless it is named in `locker` and started by the `lock` action. `Session::serve` and `Compositor::insert_client` take the roles to give, and `Action::Spawn` and `autostart` hold a `Started` instead of a `Command`.
* **omorfos:** the second button of a titlebar makes the window fullscreen where it maximized; double-click the titlebar to maximize. A fullscreen window is on a workspace of its own, so other windows are no longer under it, and `number` in the IPC state counts desktops only.
* **omorfos:** there is one workspace by default where there were four; name four in `workspaces` in config.yaml to have them always. Switching or sending to the workspace one past the last now makes it where it was refused. Super+1 to Super+9, Super+n and Super+Shift+n are bound by default.
* **config:** by default `Super+Space` opens the launcher and no longer the root menu, which is on `Super+Escape`, and `Super+d` does nothing. A `keys.yaml` that binds these is unaffected.
* **config:** `touchpad.natural_scroll` is now on by default. Set it to `false` to have a touchpad scroll as before.
